description: This project applies a Naive Bayesian classifier to radar velocity traces to address a real-world aviation safety problem: preventing bird–aircraft collisions. Using likelihood distributions for speed and Gaussian models of acceleration, the classifier recursively updates posterior probabilities with conservative transition rules. Initial results using speed alone reached 90% accuracy, while incorporating acceleration improved performance to 100% across 10 test tracks. The project demonstrates the power of Bayesian reasoning and feature engineering in signal classification tasks.
